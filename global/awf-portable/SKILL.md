# AWF

Read [installation](references/skill-installation.md), [workflow](references/workflow.md),
[channels](references/update-channel.md).

Explain first: installing AWF changes repository governance files; prepare a
draft PR for owner merge without rule preconditions. Report APPLIED/MISSING/
UNOBSERVED rules, warn/offer the ruleset; bootstrap never applies rules.
Preserve configuration/CODEOWNERS/instructions; name unresolved paths/remedies.
Disabled Jira uses local records; empty CI/owners warn.

Use the adoption PR checklist. CONFIGURED requires isolated installed
verification/validation, successful exits, accepted outputs/bound digests.
Status recomputes checks. ACTIVE requires independent release trust,
receipt-changing merged adoption and accepted raw default-branch AWF bytes;
unrelated product edits may coexist. Assertions cannot suffice; ACTIVE enables no adapter.

Live review/scheduled amendments/secret-repository pushes require observed
rules/mode qualification; execution needs CI/trusted owners. Otherwise prepare
changes/body for owner publication. Reuse permitted PR tools; never invent a PR.

Verify [bundled source](assets/agentic-workflow-template-v1.9.6.zip) against
[pins](assets/release.json):

```text
python -B PATH_TO_SKILL/scripts/prepare_release.py --cache-dir ABSOLUTE_EXTERNAL_CACHE --version 1.9.6
```

Use Python 3.11+, separate cache/existing parent/catalog; preserve differing/
incomplete caches. Read verified AGENTS/specification/configuration/runbooks.

Follow [routing](references/model-routing.md): twelve workers, shared independent
critic/adversarial handler, controller (fourteen slots); observed capacity binds.
One writer/path; independent reviewers. Preserve unknown usage/history/
reservations/finite retries; configuration cannot raise host ceilings.

At CONFIGURED offer defaults, Epic recommendations or custom.
Echo/apply/show unprotected `operating set`; recommendations need acceptance,
governance changes review. Use `--epic EPIC-ID`; retain floors/pins/reservations;
drain surplus.

Follow the [workflow](references/workflow.md) and verified
`.agentic/docs/23-TICKET-LIFECYCLE.md`, including gates and publisher
tree equality. Mark-ready requires an explicit owner/manager authorization record:
pre-issued request and authenticated immutable provider observation bound to
PR/head/configuration/trusted time. Log before mutation; observe `draft_cleared`.
Validation/CI cannot authorize it. Critic/specialists/final gate precede owner-ready,
never merge authority.

Read `.agentic/docs/39-BUDGETING.md`. Fresh accounting/enforcement OFF;
dormant limits exactly 4,000,000 tokens/ticket, 1,000,000,000/project lifetime.
Limits enable neither switch; enforcement requires accounting; accounting OFF
disables enforcement. Preserve upgrades; installed 1.9.5 stays unchanged/enabled.
Recommend versioned preservation, never in-place integrity-managed bytes/receipts.

For chat settings questions, run verified `workflow.py operating show`
read-only, without approval. Present switches/limits, source/commit, safe working-file
differences and offline rules UNOBSERVED warnings; readiness/adoption observe live rules.
PR/merger optional; report unobserved. No owner terminal commands.

For changes, branch from the fetched configured default branch. Edit requested
`OPERATING_CONFIG.yaml` values, preserving text/comments; accounting OFF also
disables enforcement. Run `operating validate --file PROPOSED`; invalid combinations refuse.
Present exact before/after in a draft PR under publication authority. Restricted
pushes prepare branch/body for owner publication. Owner reviews/merges
on GitHub; agents never merge. Fetch after observed merge; show effective
settings/commit. Git history/PR provide audit. Working/branch edits
have no protected effect. Protected set explains the PR route.
Keep Git metadata outside worker write authority. Host rules/owner govern merge;
default-branch pushes/owner rights can bypass this. Offer the ruleset.
`merge_gate.trusted_owner_ids` retains its merge-gate use.
Calendar shares this route: show timezone/work/review/EoD settings. Defaults:
24/7 work; weekday review 07:00-17:00 Europe/London; daily EoD 17:00.
Validate proposals; only merged/fetched calendars apply; malformed policy refuses.

Reporting shares this route: default OFF; off/teams/slack/both with complete
project/repository/scope/platform/destination/revision/secret_ref bindings. Validate
offline; reachability UNOBSERVED. Working edits cannot apply; fetch merged policy.
Controller re-admits mode/bindings before POST, including injected senders.
Prepare links/secrets outside transactions; recheck dependencies before retention.
OFF retains suspension with cleared/absent bindings; exclude disabled hours.
Preserve receipts/withdrawal/corrections/two-send ceilings.

Budgets cover explicitly enrolled AWF sub-agents/attributable tools/retries;
exclude controller/independent/ULTRA agents. Preserve UNKNOWN/history/failures/
reservation identities; never reset totals/invent zero usage. OFF needs no new
ledger/telemetry/reservations/quotas/warnings/overrun quarantine. Independent
security/permissions/review/merge/host-capacity/bounded-recovery controls remain.

Only controller writes Jira: WORKER_STARTED=In Progress; PR_READY=In Review;
JIRA_RECONCILED=Done after observed merge. Follow [workflow](references/workflow.md):
read before/after, stop mismatches/unknowns without retry. BLOCK/PARK/Epics never
transition; owner-closure tickets wait.

Declare tier/closure; retain boundaries/candidate-bound reviews/owner cap
dispositions. Escalate within approved limits; increases/weaker review/
reconciliation enablement need human direction. Candidate policy cannot approve
itself. Report results.
