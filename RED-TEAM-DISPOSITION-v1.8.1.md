# Disposition of the v1.8 review

This patch responds to the review dated 13 September 2026. Offline implementation/acceptance, live external-engine qualification and public publication are separate outcomes. Detailed validation accompanies the built archive; this document does not substitute for that evidence.

| Finding | Correction and remaining boundary |
| --- | --- |
| N1: transport errors lose reports | Validate raw JSON and transport envelope types, wrap controlled transport/parse failures as adapter errors and retain error reports. Regression tests exercise raw transport responses. Runner/process loss can still prevent artifacts and remains failure, never a clean review. |
| N2: privileged execution and secrets | Require immutable trusted execution code, a protected-default PR target and separate model/publisher environments with exact deployment branch restrictions. Remove the candidate-context review trigger; a trusted coordinator must rerun the existing gate after reviews change. GitHub currently documents default-branch workflow context for `pull_request_target`; the prior template still explicitly checked out arbitrary PR base code. No live exploit or server configuration is claimed. |
| N3: benchmark overclaim | Rename the mechanism consistently to self-reported structured-decision smoke. It runs no model and ships a public rubric which can be copied. Packet/shape grading remains useful; comparative prompt quality requires separately executed, held-out evaluation and is unmeasured here. |
| N4: unbounded aggregate input | Enforce serialized UTF-8 aggregate input and actual HTTP request limits, with a real byte-based diff cap. Reject oversized input before model API use rather than silently dropping files. These bounds complement output-token and job limits; they do not predict provider pricing. |
| N5: editable retry ceiling/cohort drift | Persist a conservative project ceiling in the protected ledger. Ordinary configuration raises block; a separate trusted-host operation records bound, idempotent authorization assertions using comparison against the current ceiling. Preserve safe closure, charges and audit. Normalize exact default representations for effective identity while reporting retained legacy hashes; substantive policy differences stay separate. |
| N6: weak disposable guard | Require independently provisioned external marker bytes and pin bound to the disposable repository's numeric identity, PR/head, expiry and allowed probes. Recheck live identity before mutation. This adds a deliberate out-of-band prerequisite, not human authentication; the host must control marker provisioning and access. No live destructive probe was run for this patch. |
| N7: spoofable prompt framing | Label every head-supplied contract/claim as untrusted candidate data, encode it and use collision-checked framing. Prompt delimiters are formatting, not a security boundary. The model retains no executable tools or write token; actual injection resilience still requires live qualification. |
| N8: setup/reference/timing gaps | Ship an inert external policy example, resolve policy documentation references, align per-attempt and job budgets, and document actual setup and rerun responsibilities. Existing project policy and required engine remain owner-controlled. |

All five native role prompts restore worker/critic record vocabulary, per-criterion outcomes, command/exit/clean-tree evidence and the five-part state/action/owner/resume-trigger/user-action handoff within their per-file budgets. Historical migration guides remain available; [the patch migration](MIGRATION-v1.8-to-v1.8.1.md) specifies safe adoption and rollback.

The external adapter remains disabled/unqualified until a project completes [server setup and canary qualification](.agentic/docs/28-EXTERNAL-REVIEW.md). A check name alone does not prove trusted workflow provenance; required-workflow/ruleset protection and bypass restrictions must be qualified on the actual host. Offline tests do not establish those settings, external model quality, publisher authentication or ownership. This remains an unsigned Apache-2.0 distribution with explicitly stated publisher metadata.
