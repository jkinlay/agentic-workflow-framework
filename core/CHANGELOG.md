# Change history

## 1.8.0 — 13 September 2026

Re-review follow-up: finite ticket-wide reconciliation retries, preserved policy-hash evidence cohorts, precise operator-assertion boundaries, substantive native prompts and a standing decision benchmark. Restored the split external model/publisher adapter as one optional core component, requiring live qualification. Replaced documentation stubs with focused runbooks and migrations; per-file limits replace the global word cap. Hygiene runs on the real source and checks future major versions and additional text formats. Added CLI failure-path tests. Publisher signatures remain explicitly unavailable.

## 1.7.0 — 13 September 2026

Red-team hardening: monotone routing, structured CLI/config errors, conservative operator reconciliation, explicit capacity reporting, process-level adapter tests and generated/version-checked prompts. Defaults now include three independent reviewers total, one per workstream. Documentation is consolidated and budget-checked. Core is Apache-2.0, published by Jonathan Kinlay. Native execution remains host-dependent; cap increases require human direction.
