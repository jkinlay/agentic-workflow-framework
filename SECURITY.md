# Security

Publisher: Agentic Workflow Framework maintainers. Core licensing is Apache-2.0; see LICENSE/NOTICE. No cryptographic publisher signature or response SLA is claimed.

Report vulnerabilities through the repository's configured private security
reporting channel. Do not open a public issue containing exploit details or
secrets. Include release hash, affected component and a redacted reproduction.
Pause affected automation and preserve evidence. Acknowledgement and
remediation times are not guaranteed. A contact channel is not a cryptographic
identity proof.

Upstream CODEOWNERS names @maintainer. Required owner review and bypass restrictions need server configuration; product repositories keep their own owners. Candidate governance cannot approve itself.

Digests identify bytes, not publishers. Offline tests do not qualify live hosts, credentials, APIs or schedulers.
