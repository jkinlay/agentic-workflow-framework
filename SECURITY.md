# Security reporting

Report vulnerabilities privately to Jonathan Kinlay at [jkinlay@gmail.com](mailto:jkinlay@gmail.com). Include the release hash, affected component and a redacted reproduction; do not publish exploit details, credentials or private project data in an issue.

See the [core security policy](core/SECURITY.md) for the trust and reporting boundaries. No response-time guarantee or cryptographic publisher signature is claimed. Repository review settings and live qualification require separate owner configuration.
