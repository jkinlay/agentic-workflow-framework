# AWF v1.8.4 historical pilot summary

This retained record is a sanitized historical summary, not a release
qualification, model-quality claim, or runnable protocol. The earlier pilot
prepared twelve synthetic cases with fixed decision criteria and no project
data. It used bounded, sequential calls with no automatic retry.

The protocol distinguished current from stale evidence, bounded owned work
from unaffected work, and kept successful and incomplete coverage separate.
It evaluated decision text only, so it did not exercise project actions or
prove provider enforcement. The historical result remains separate from the
current source and cannot qualify its adapters, hosts, credentials or release.

No raw prompts, responses, host information, filesystem locations, account
identities, usage metrics, evaluator-material locations, or execution logs are
included in this upstream distribution. Any future measurement needs a fresh,
reviewed protocol and independently retained evidence outside the release.
