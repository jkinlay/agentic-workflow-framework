# Adopt AWF

Inspect project instructions, accepted version, configuration, worktrees and owners. Preserve explicit version selectors. Verify catalogue/archive pins before running source. Compare owner releases and the bundled version; do not downgrade because a catalogue is old.

Read verified `.agentic/SPECIFICATION.md` and `.agentic/docs/20-NEW-PROJECT-SETUP.md`. Prepare isolated reviewed adoption, preserving project values and history. Cross-version adoption uses backed-up install; upgrade mode is same-version only.

Validate the target, not the source defaults. Keep human governance/merge acceptance and verify the accepted checkout before reporting adoption. A skill replacement, catalogue entry or PR is not an active project upgrade. No authenticated remote means a local prepared change, not an invented PR.
