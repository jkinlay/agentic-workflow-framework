# Routing

Use verified source `.agentic/docs/27-MODEL-ROUTING.md` and the target's adopted configuration. Skill updates do not inject routing into older projects.

Inspect actual host model/effort capabilities. Classify ticket/phase risk and verification strength, preserve pins/review floors, reserve before launch, then settle trustworthy observations. The helper neither launches models nor enforces provider limits.

Automatic escalation stays within reviewed limits; never raise caps to make it fit. Keep one protected shared ledger outside worktrees. Unknown usage is not zero. Reconciliation is disabled until human-enabled operator policy. The helper records assertions; the host/operator must establish authority and termination/remediation. Preserve charges/audit and finite ticket-wide retry limits across policy changes.

Reviewers use independent contexts, one per stream by default, bounded by shared host capacity. Shadow evidence proposes experiments rather than autonomous policy changes. Keep historical policy cohorts separate. The scheduled adapter retains separate static model settings/enrollment. For external-engine review, read verified `.agentic/docs/28-EXTERNAL-REVIEW.md`; native reviewers do not qualify that gate.
